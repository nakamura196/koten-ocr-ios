> We are looking for testers to help release the app on Google Play.
> Installing the APK does not count as joining the test. If you'd like to help, please use the [testers page](android-en.html) instead.
{: .point }

### Install

1. On your Android device, download **KotenOCR-2.1.0.apk** (about 236 MB) from the [GitHub release page](https://github.com/nakamura196/koten-ocr-android/releases/latest). Wi-Fi is recommended.
2. Open the downloaded file. If asked, allow your browser (or Files app) to install unknown apps.
3. Tap "Install".

- Requires Android 8.0 or later on a 64-bit (arm64) device
- The first launch takes about 20 seconds to prepare the models

### Notes

- The APK installs as a separate app from the Google Play version, so you can have both.
- Updates are not automatic; new versions will be posted on the release page.
- Once the Google Play version is available, we recommend switching to it. Scan history is not carried over.
