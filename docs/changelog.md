日付は日本時間です。最新は 2.1.1（2026年11月3日） です。


### 2.1.1（2026年11月3日）

- 枠を 4 色（朱・藍・萌黄・江戸紫）で塗り分け、隣り合う行の境目を見分けやすく（結果画面・枠の編集とも）
- 枠の編集で、指の動きに枠が遅れずについてくるように
- 枠の辺のつまみを追加し、幅だけ・高さだけを変えられるように。細い行でもつまみをつかみやすく
- 選んでいない枠に触れたときは、選ぶだけで動かさないように。選んだ枠の近くで隣の行に触れたときは、隣の行を選ぶように
- 枠の編集中も、ダブルタップで拡大・全体表示を切り替えられるように

### 2.1（2026年11月1日）

- 切り抜き画面に「自動補正」を追加。ページの四隅を探して、斜めに撮った頁をまっすぐに直す。気に入らなければ「元に戻す」
- 結果画面に「確信度」のスライダーを追加。上げると自信のない枠から隠れる（表示だけで、読み取り結果は変わらない）
- 細い行（傍書など）の番号を読める大きさにし、重なる番号をずらして表示
- 近代モードで、見出しなど短い行を短い行用のモデルで読むように（NDLOCR-Lite と同じ）。枠の座標と検出の線引きも NDLOCR-Lite にそろえた
- 読み順: 1 つの行が細切れに検出されたとき、上から順に並ぶように
- 白黒（16 ビット）の画像を回転すると失敗する不具合と、画像の向きの扱いを修正
- 履歴の保存を確実に（書き込みの途中で終了しても壊れにくく）
- アップデートの案内を、操作を妨げない形に
- 翻訳の API キーをこの端末だけに保存（機種変更やバックアップからの復元では再入力が必要）
- プライバシーマニフェストを追加し、プライバシーポリシーを実際の動作に合わせて更新

### 2.0.1（2026年10月30日）

- 最初の説明で、撮影のほかに写真から読み込めることを案内
- 切り抜き画面の回転ボタンに「回転」と文字を表示

### 2.0（2026年10月30日）

- ホームに「サンプルの頁で試す」を追加。『竹取物語』・『源氏物語』（古典籍）と国立国会図書館の資料（近代）の 3 頁を選ぶとすぐに読み取る
- 結果画面の行番号を枠の外（縦書きは上、横書きは左）に出し、行頭の文字を隠さないように。2 桁の番号も折り返さない
- 行番号に白い縁と半透明をつけ、選んだ行の番号は濃く手前に表示。枠の線は行の太さに合わせ、小さな番号でも枠との間を空ける
- 4点補正で角を動かした直後に、ページの自動検出が遅れて終わると、動かした角が元に戻ることがある不具合を修正
- 近代モードで、1行だけの見出しや図の説明（キャプション）が読み取られないことがある不具合を修正。国立国会図書館の NDLOCR-Lite と同じ行を読むように
- 新聞のように行の多い紙面で、100 行を超えた分が読まれない不具合を修正（公式の NDL の OCR と同じく上限なし）
- 確認画面で最後に選んだモード（古典籍／近代）を次回も選択。サンプルを試しても変わらない
- 起動時にホーム画面を表示（撮影する／写真から選ぶ／履歴／設定）。いきなりカメラが開かないように変更
- カメラ画面にホームへ戻るボタンを追加
- 翻訳が別の履歴に保存されることがある不具合を修正
- 結果画面で編集したテキストが履歴に保存されない不具合を修正
- 回転後に「スキップ」すると回転が失われる不具合、切り抜き枠の移動が加速する不具合を修正
- カメラの撮影ボタンの二重タップ防止、撮影失敗時のエラー表示、カメラ未許可時の案内と設定ボタンを追加
- OCRエラーを日本語/英語のわかりやすい文言と「撮り直す」ボタンで表示
- 履歴一覧をサムネイル化して高速化。削除前に確認を表示
- VoiceOver: 履歴行に日付と先頭の文を追加、結果画面にテキスト編集ボタンを追加、拡大リセットにラベルを追加
- 書き出しファイル名に日時を付与（例: KotenOCR_20261029_2154.txt）
- 不足していたローカライズ文字列と権限説明（InfoPlist.strings）を追加
- カメラ画面に「書類スキャン」を追加（VisionKit）。ページの端を自動検出し、斜めに撮っても補正。最後に使った方式を次回も使用
- カメラに傾きガイドを追加（水平器と「資料と平行に構えてください」）。設定でオフにできます
- 切り抜き画面に4点補正モードを追加。四隅を個別に動かして台形ゆがみを補正
- 撮影した資料の小さな傾き（±10°以内）を自動で補正してから行を検出するように。傾いたページで枠が隣の行と重なり、隣の行の文字が混ざる問題を軽減
- 設定に「傾きを自動補正」を追加（既定ON）
- OCR結果・履歴・書き出しの画像は、補正後の（OCRを実行した）画像に統一
- 古典籍モードで、斜めから撮ったページの行ごとの傾きに対応。傾いた行は行に沿って切り出して読むため、隣の行の文字が混ざりにくい。同じ行を二重に検出した場合の重複行と、「□□□□」だけの行も表示しない
- デザインを一新：文書と読み取った文字は和紙の色・明朝体・朱で表示し、操作ボタンは iOS 26 の Liquid Glass（iOS 16〜25 では白と朱の板）に
- アプリアイコンを和紙・墨・朱の配色に変更（ダーク・色付きアイコンにも対応）
- ホームに「最近の読み取り」を最大3件表示。押すとその結果を開く
- 読み取り中に朱の光が進み具合に合わせて動き、見つかった行が読む順に現れる。完了時に朱印を押す動きと触覚
- 初回の説明で、写本の頁に実際の読み取り結果（枠と文字）を読む順に再生。撮影ボタンと範囲の角に一度だけの吹き出し（設定から再表示可）
- 履歴が空のときの絵、文字が見つからなかったときのコツ、カメラが使えないときの案内画面を追加
- 範囲選択の後は「古典籍／近代」を選んで「読み取る」を押す形に変更。コピーは右下のボタンから、完了は上に短く表示
- 「視差効果を減らす」設定では動きをフェードに置き換え。文字の大きさ設定（アクセシビリティサイズを含む）に合わせて配置を調整
- 結果画面に「枠を直す」を追加：枠の選択・移動・大きさ変更・削除・追加・分割・結合ができ、変えた枠だけを「再認識」して読む順を並べ直す。元に戻す／キャンセル対応、履歴にも保存
- 2枚目以降の解析で落ちることがある不具合を修正。解析のたびにメモリ使用量が増え続けていた（文字検出を毎回別のスレッドで実行し、スレッドごとに約100MBの作業領域が残っていた）。撮影・写真の画像は長辺4096pxに縮小して取り込み、新しい撮影の前に前の画像を解放

### 1.3.2（2026年3月24日）

- メモリ使用量を大幅削減。起動時に選択中のモードのみロード（遅延ロード）
- DEIMDetector前処理を最適化（ピークメモリ63MB→2.4MB）
- 並列認識タスクを最大4バッチに制限（メモリスパイク防止）
- メモリ警告時に未使用モデルを自動解放
- MetricKitによるクラッシュ診断収集を追加
- クラッシュリスクの追加修正（IoU境界チェック、ゼロ除算防止、force unwrap除去）

### 1.3.1（2026年3月23日）

- 近代OCRの検出精度を改善。NMS（IoU=0.2）を追加し重複検出を除去
- 近代OCRでline_*クラスのみをOCR認識対象に変更（本家ndlocr-liteと同じ挙動）
- 検出パラメータを本家と統一（scoreThreshold=0.2, maxDetections=100）

### 1.3.0（2026年3月22日）

- NDLOCR-Lite（近代活字OCR）に対応。古典籍と近代の2つのOCRモードを切り替えて使用可能
- DEIMv2検出器とカスケードPARSeq認識器を追加
- 確認画面で「古典籍 OCR」「近代 OCR」をワンタップで選択
- OCR結果から「戻る」で確認画面に戻り、別モデルで再実行可能
- 認識処理の並列化（古典籍1.4x、近代6.7x高速化）
- スプラッシュ画面を追加
- フィードバック送信機能を追加
- クラッシュリスクの修正

### 1.2.2（2026年3月19日）
